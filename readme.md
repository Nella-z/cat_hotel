# Котейка — сайт гостиницы для кошек на WordPress

Одностраничный адаптивный сайт вымышленной гостиницы для котов и кошек в Санкт-Петербурге. Учебный pet-проект: вёрстка по макету, слайдеры, интерактивная карта и **собственная тема WordPress**, в которой номера, преимущества и отзывы редактируются из админ-панели.

Проект существует в двух версиях:

| Версия | Что это |
|---|---|
| **Статическая** (HTML, CSS, JS) | Исходная вёрстка по макету. Демо: https://nella-z.github.io/cat_hotel/ |
| **WordPress-тема** (этот репозиторий) | Та же вёрстка, но содержимое берётся из записей и полей WordPress |


## Что есть на странице

- Первый экран с названием, слоганом и кнопкой бронирования (звонок по `tel:`)
- Блок «Почему мы?»: карточки преимуществ в сетке (до шести карточек)
- «Номера»: слайдер (Swiper) с пагинацией и стрелками; количество номеров не ограничено
- «Отзывы»: слайдер, количество видимых карточек меняется от ширины экрана (1 → 2 → 3 → 4)
- «Как нас найти»: контакты и интерактивная карта (Leaflet + OpenStreetMap) с собственной меткой
- Бургер-меню на мобильных устройствах
- Якорная навигация по секциям с плавной прокруткой


## Что редактируется из админ-панели WordPress

Весь текст и фотографии на странице меняются без правки кода.

**Блоки с карточками — это обычные записи, разложенные по рубрикам:**

| Рубрика (слаг) | Блок на сайте | Что используется из записи |
|---|---|---|
| `why-us__inf` | «Почему мы?» | заголовок, текст, миниатюра (иконка 91×91 px); выводится не больше 6 записей |
| `room__swiper-slide` | «Номера» (слайдер) | заголовок, текст (описание и цена), миниатюра (фото номера) |
| `comment__swiper-slide` | «Отзывы» (слайдер) | заголовок = имя автора, текст = отзыв, дата публикации |

Чтобы добавить номер или отзыв, достаточно создать новую запись в нужной рубрике: в слайдере она появится сама.

**Контакты — это настраиваемые поля (плагин Advanced Custom Fields):**

| Поле | Где используется |
|---|---|
| `city` | город на первом экране и в блоке «Как нас найти» |
| `street` | улица и дом в блоке «Как нас найти» |
| `tel` | номер для кнопок «Забронировать» (ссылка `tel:`) |
| `phone` | телефон в блоке «Как нас найти» |
| `mode` | режим работы в блоке «Как нас найти» |
| `e-mail` | почта в блоке «Как нас найти» |


## Стек

- **WordPress**: собственная тема без конструкторов страниц
- **PHP**: шаблоны темы, вывод записей через `get_posts`
- **Advanced Custom Fields**: контакты гостиницы
- **HTML5**, БЭМ-именование классов
- **CSS3**: Grid, Flexbox, media queries (1024 / 750 / 640 px)
- **JavaScript** (jQuery входит в WordPress)
- **Swiper 12**: слайдеры
- **Leaflet 1.9.4 + OpenStreetMap**: карта
- **Google Fonts** (Philosopher, Lato)


## Как устроена тема

- `functions.php` подключает стили и скрипты через `wp_enqueue_style` и `wp_enqueue_script` с правильным порядком зависимостей. Версия своих файлов берётся из времени их изменения, поэтому браузер всегда загружает свежую копию после правок.
- В JavaScript передаются настройки темы (`theme_vars`): адрес `admin-ajax.php` и путь к папке с изображениями (нужен, например, для метки на карте).
- В теме включена поддержка миниатюр записей, логотипа, автоматического заголовка страницы (`title-tag`) и HTML5-разметки.
- Главная страница строится шаблоном `home.php` (Template Name: `home`).
